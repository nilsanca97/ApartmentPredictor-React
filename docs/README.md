# README

This project is a practical exercise, where I create a React Single Page Application (SPA) using Vite as the build tool. 

The producto goal of this exercise is to develop and program the frontend of the ApartmentPredictor project, that is, the visible part of the website and the screen the user interacts with.

On the webpage, a list of all the apartments is displayed along with tree buttons that allow users to perform the basic actions: create new apartments, view the details of each apartment and delete apartments.

All of this has been programmed using conditional rendering, which is a very important feature in React that allows elements to be shown or hidden on the screen depending on what is happening in the application.
